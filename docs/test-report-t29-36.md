### T-30 媒体信息 — 1/1 通过（修复 1 个 bug）

| 功能 | 操作 | 结果 |
| --- | --- | --- |
| 多文件解析 | mp4 + mp3 同时上传解析 | ✓ 两个文件均输出独立结果卡片 |

**发现并修复的 bug**：多文件解析时第二个文件的输出丢失——根因是 `runTask` 内同一 ffmpeg 实例连续多次 `run`，0.11 的 logger 在第二次 run 失效（parseArgs 泄漏）。改为 `runBatch`（每个文件独立实例 + 退出重建）后两个文件均正确解析。
- mp4：容器 mov、时长 8s、h264 640×360 25fps + aac 44100Hz mono
- mp3：mp3 mono 128kb/s

### T-31 视频抽帧/倍速 — 3/3 通过（修复 1 个 bug）

| 功能 | 操作 | 结果 |
| --- | --- | --- |
| 抽帧（间隔） | 8s 视频 / 间隔 2s | ✓ 输出 4 帧 PNG |
| 抽帧（时间点） | 指定 2s | ✓ 输出 1 帧 PNG |
| GIF 转视频 | test.gif → mp4 | ✓ 输出 gifvideo_*.mp4 |
| 倍速转换 | 2x | ✓ 输出 speed_*.mp4 |

**发现并修复的 bug**：间隔抽帧只输出 1 帧——根因是输出文件名 `frames_*.png` 缺少 `%d` 序号模式，ffmpeg 无法推断多帧输出只写 1 帧并报错。改为 `frames_*-%d.png` 后 8s/2s 正确输出 4 帧。
